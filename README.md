# 會考自然考點導航

111–115 年國中教育會考自然科共 250 題，依國中自然（生物、理化、地科）單元整理出題次數、全國通過率與難度，附原題與解題引導（讀懂題目 → 破題 → 觀念引導 → 一步一步來）。

網站：https://bgjd315-cloud.github.io/cap-science-map/

- `index.html`：網站本體（單一檔案，資料內嵌）
- `q/`：題目圖，裁切自心測中心公布的歷屆試題
- `art/`：吉祥物主圖與單元小圖（Canva AI 繪製）
- `tools/`：建置腳本 `build.py`、檢查腳本 `lint.py`、網站模板 `template.html` 與資料（`data/111.json`～`115.json` 等）
- 每年加入新一年會考：照 [`tools/UPDATE.md`](tools/UPDATE.md) 做

資料來源：國中教育會考網站（心理與教育測驗研究發展中心）歷屆試題、選擇題參考答案與各題通過率。解題引導為整理撰寫，非官方解答。
