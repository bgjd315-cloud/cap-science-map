# 會考自然 資料格式與解題引導規格

讀者是國中生，程度從 C 到 A 都有。目標是讓學生「自己想得出來」，不是看懂答案。語氣像老師在旁邊陪寫：句子短、口語、具體；不寫客套話。所有字串遵守 data/style.md。

## 每一題一筆 record（JSON 物件）

| 欄位 | 內容 |
|---|---|
| exam | 科別：`生物`、`理化`、`地科` 三選一（看這題主要考哪一科） |
| year | 年度（整數，例如 115） |
| no | 題號字串 `"1"`～`"50"` |
| type | `單題` 或 `題組`（共用一段文章或圖表的題目都算題組） |
| points | 1 |
| unit | data/units.json 的代碼，只能用這些 |
| secondary | 其他也用到的單元代碼陣列，可空 |
| topic | 小主題，10 字以內（例如「光合作用的產物」「串並聯電阻」） |
| context | 生活情境或實驗情境的簡述（例如「校園水池生態」「滑輪吊重物」），沒有就空字串 |
| stem | 題目重點的純文字摘要，1–3 句（圖片載不到時才會顯示） |
| answer | 官方答案，寫成 `(C)` |
| solution | 1–2 句解法摘要 |
| pitfall | 一個常見錯誤，簡短 |
| difficulty | 依通過率 p：$p\ge0.70$ 易、$0.45\le p<0.70$ 中、$p<0.45$ 難 |
| rate | 通過率數字（例如 0.64） |
| verified | 自己解過且和官方答案一致才填 true |
| detail | 解題引導，見下 |

## detail（解題引導）

1. `idea`：一句話的破題結論（整題策略）。
2. `read`（讀懂題目）
   - `given`：已知條件陣列，一條一項。圖表、實驗裝置、數據表要把關鍵數值與變因寫出來，並註明「圖上標示」「表中數據」。題組要寫出這題用到的那部分資料。
   - `ask`：一句話，題目到底在問什麼（例如「哪一個選項的推論正確」要寫清楚是要判斷什麼）。
   - `keys`：2–4 組 [關鍵字或條件, 它在提示你什麼]。挑學生容易漏看或誤解的字眼：「操縱變因」「對照組」「錯誤的是」「同時」「最大」、單位、箭頭方向、圖的坐標軸是什麼。
3. `crack`（破題）：2–4 題 [{q, a}]。蘇格拉底式提問，順序像真的在想：先看問什麼 → 這是哪個觀念 → 用哪個證據或公式。最後一題的 a 要點出整題策略。
4. `concepts`（觀念引導）：1–3 個 {name, body, eg}。body 2–4 句，用國中生聽得懂的話講「這個觀念是什麼、為什麼、這題怎麼用」；可提醒常見迷思。eg 可省，放一個極短的生活例子或反例。
5. `formulas`：計算題才放公式框 {name, tex, vars:[[符號, 意義與單位]], cond}；tex 不加 $；概念題給空陣列。
6. `steps`：3–6 步，每步 {q, hint, calc, why}
   - q：這一步要做什麼（提問句）。
   - hint：必填，一句提示，只指方向不給答案。
   - calc：一行一個推理或一行一式。概念題寫推理句，例如「葉綠體只在照光時進行光合作用」「所以試管甲產生的氣泡最多」。計算題換單位、代公式、算數都要分行。
   - why：可省；為什麼可以這樣推，或容易錯在哪。
   - 判斷各選項的題目，可以一步處理一個或兩個選項，最後一步總結。
7. `answer`：同 record 的 answer。`approx`：計算題除不盡時用。`check`：代回檢查、單位檢查或合理性判斷，一句。
8. `wrong`：有代表性的錯誤選項 [{opt, how}]，每條自己推過。
9. `tiers`：空陣列（自然科沒有非選題）。
10. `takeaway`：一句話心法。

## 格式示意（非真題，只示範寫法）

```json
"read": {"given": ["甲、乙兩組相同的水蘊草放在相同的水中（表中數據）", "甲照光、乙放在暗處，其他條件相同", "$30$ 分鐘後收集到的氣體體積：甲 $12\\ \\text{mL}$、乙幾乎沒有"],
         "ask": "這個實驗要比較的是哪一個因素對光合作用的影響。",
         "keys": [["其他條件相同", "只有一個變因不同，那個就是操縱變因。"], ["氣體", "水蘊草照光時放出的是氧氣。"]]},
"crack": [{"q": "甲、乙兩組哪裡不一樣？", "a": "只有有沒有照光。"},
          {"q": "收集到的氣體可以代表什麼？", "a": "代表光合作用的快慢，因為光合作用會放出氧氣。"},
          {"q": "整題怎麼判斷？", "a": "找出唯一不同的條件，再看結果差在哪裡，就知道這個條件的影響。"}],
"concepts": [{"name": "操縱變因與對照實驗", "body": "實驗一次只改變一個條件，其他條件都要相同，才能確定結果的差異是這個條件造成的。被改變的條件叫操縱變因，跟著改變的結果叫應變變因。", "eg": "比較兩種肥料時，如果花盆大小也不同，就不知道是肥料還是花盆造成的差別。"}],
"steps": [{"q": "先找出操縱變因。", "hint": "比較兩組的條件，找出唯一不同的地方。", "calc": ["甲照光、乙不照光", "其他條件相同", "操縱變因是光照"], "why": ""},
          {"q": "結果說明了什麼？", "hint": "氣體多代表哪個作用比較旺盛？", "calc": ["甲有氧氣產生，乙幾乎沒有", "照光時才進行光合作用"], "why": ""}]
```
